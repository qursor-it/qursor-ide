# Canvas Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Canvas mode: per-project `canvas/*.canvas` files (JSON Canvas 1.0) edited on a Miro-like React Flow board, with the project's Claude session on the right to reason with.

**Architecture:** Rust owns listing, creating and conditionally writing canvases, plus a second file watch and the canvas↔session link (migration 9003). The renderer adds a third `AppMode`, a canvas sidebar, a lazy-loaded board built on `@xyflow/react` with a pure JSON Canvas mapper, and an agent panel that mounts the existing `Terminal` and pastes into it with `sendToSession`.

**Tech Stack:** Tauri 2, Rust (rusqlite, notify, sha2), React 19, Zustand, TanStack Query, `@xyflow/react` (new, MIT), `perfect-freehand` (new, MIT), vitest, Playwright smoke.

**Spec:** `docs/superpowers/specs/2026-11-17-canvas-design.md` (mockup alongside). Read it first.

## Global Constraints

- Work on branch `feat/canvas` in its own worktree off `develop` (skills `pull-requests`, `spec-and-adr-workflow`). Commits are small and prefixed (`feat:`, `test:`, `docs:`).
- File location: `<project root>/canvas/<slug>.canvas`. Slug: ASCII-fold, lowercase, non-alphanumerics become `-`, collapse/trim, max 60 chars, empty becomes `canvas`. Collisions become `-2`, `-3`, … and are created with `create_new`, so nothing is overwritten.
- Format: JSON Canvas 1.0, 2-space pretty print, top-level `title`. Extras: `x-kind` (`sticky|shape|ink`), `x-shape` (`rect|ellipse|diamond`), `x-points`, `x-author: "agent"`. **Every unknown field round-trips unchanged.**
- Canvas commands resolve paths with `services/ide/scope.rs::resolve_within` under the project root. Blocking work goes through `commands::off_main`.
- UI: `@factorai/ui` primitives only (no raw `<button>`/`<input>`); `IconButton` for icon-only controls; no HTML5 drag-and-drop; `DESIGN.md` tokens; follow the app theme.
- Migration number `9003`, feature `F44`, ADR `0103`.
- Context line pasted to the agent, exactly: `[canvas: <absolute path> · selected nodes: <ids or none> · JSON Canvas 1.0; mark nodes you add with "x-author":"agent"; use colour presets "1"-"6", not hex; keep fields you don't know]`, then a newline and the user's text.
- Autosave 600 ms after the last change, on blur and on mode switch. Ctrl+S saves now.

## Review Focus

1. **A hand-edited or agent-broken `.canvas` that is invalid JSON.** Show an error card with "Open as text" (the existing viewer) and **never autosave over it**. Pinned in Task 2 (parse returns an error) and Task 4 (no write while in error).
2. **The open canvas is deleted on disk.** Show a banner. Autosave must not recreate the file. Pinned in Task 4.
3. **The agent writes while the user is dragging.** `write_canvas` refuses, the banner appears, and nothing is lost. Pinned in Task 1 (Rust) and Task 4 (smoke).
4. **A title that is only emoji or punctuation, or one with accents.** Pinned in Task 1 slug tests: `"🎉🎉"` → `canvas`, `"Idee è Già"` → `idee-e-gia`.
5. **A project whose folder is missing** (`project.path` absent, or not on disk). Hide "+ New canvas", and `list_canvases` returns `[]` without an error. Pinned in Task 1 and Task 3.

**Interfaces — Produces:**
- `type CanvasDoc = { title?: string; nodes: JcNode[]; edges: JcEdge[]; [k: string]: unknown }`
- `parseCanvas(text: string): { ok: true; doc: CanvasDoc; nodes: Node<CanvasNodeData>[]; edges: Edge<CanvasEdgeData>[] } | { ok: false; error: string }`
- `serializeCanvas(doc: CanvasDoc, nodes: Node<CanvasNodeData>[], edges: Edge<CanvasEdgeData>[]): string`

- `newNodeIds(prev: CanvasDoc | null, next: CanvasDoc): Set<string>`

  - `roundtrip_is_stable`: `serialize(parse(serialize(parse(t))))` gives the same string, with 2-space indent and a trailing newline.
  - `maps_kinds`: `x-kind:"sticky"` → RF type `sticky`; plain `text` → `text`; `group` → `group`; a child inside a group gets `parentId` and relative position, and absolute again after serialize.

### Task 4: Editing, autosave, external changes

**Files:**
- Create: `components/canvas/nodes/{StickyNode,ShapeNode,TextNode,FrameNode,FileNode,LinkNode}.tsx`, `components/canvas/CanvasToolbar.tsx`, `components/canvas/SelectionToolbar.tsx`, `components/canvas/useCanvasDoc.ts`, `components/canvas/useCanvasDoc.test.ts`, `components/canvas/history.ts`

**Interfaces — Produces:**
- `useCanvasDoc(projectId: string, path: string)` returns:
  - `status: 'loading' | 'ready' | 'invalid' | 'deleted'`
  - `nodes`, `edges`, `onNodesChange`, `onEdgesChange`, `onConnect`
  - `update(fn: (s: { nodes; edges }) => { nodes; edges }): void`
  - `saveState: 'saved' | 'saving' | 'unsaved' | 'conflict'`
  - `saveNow(): Promise<void>`
  - `newIds: Set<string>`, `touch(id: string): void`
  - `conflict: null | { reload(): void; keepMine(): void }`
  - `undo()`, `redo()`
- Logic of `useCanvasDoc`:
  - Keep `baseSha` from the last read or write.
  - Debounce 600 ms, then `writeCanvas(…, baseSha)`. `Written` updates `baseSha`; `Conflict` sets `saveState='conflict'`.
  - On `canvas:changed` for this path: re-read. Same sha, ignore (our own write). If not dirty, replace the state, add `newNodeIds(prevDoc, nextDoc)` to `newIds`, and update `baseSha`. If dirty, set conflict.
  - `keepMine` writes with the disk sha. `reload` discards local and re-reads.
  - Never write while `status` is `invalid` or `deleted`.
  - Saves now on unmount, blur and mode switch if dirty.
- `history.ts`: snapshot stack (max 100) of `{nodes, edges}`, pushed on drag-stop / edit-commit / add / delete.

- [ ] **Step 1: Write failing vitest tests in `useCanvasDoc.test.ts`** (mock `cmd` like other hook tests do; use fake timers):
  - `autosaves_after_600ms`: one change, advance 599 ms → no write; at 600 ms → `writeCanvas` called once with `expectedSha256 = baseSha`.
  - `conflict_on_refused_write`: `writeCanvas` resolves `{kind:'Conflict'}` → `saveState === 'conflict'`, local nodes kept.
  - `external_change_clean_reload_marks_new`: a clean state plus a `canvas:changed` event with a new node `g1` → `nodes` contains `g1`, `newIds.has('g1')`.
  - `external_change_dirty_sets_conflict`: dirty plus the event → conflict and no reload.
  - `own_write_echo_ignored`: an event whose re-read sha equals the just-written sha → state unchanged, no conflict.
  - `no_write_when_invalid_or_deleted`: `status` `invalid` → a change gives no `writeCanvas`. A re-read that rejects with NotFound sets `status === 'deleted'` and no write.
