# E3 — PTY and process ownership
Depends on E1/E2. Inspect services/terminal.rs, terminal/agent_use.rs, ssh/pty.rs, ssh/pool.rs, commands/sessions.rs, commands/servers.rs, platform/, lib.rs and state.rs. Read ADR-0002, 0005, 0111 and server policy ADRs. SSH bridge already uses portable_pty traits; server_open_shell optionally attaches tmux. A persistent SSH tab is not a managed agent session.
Extract process/PTy operations and supervision; separate terminal bytes from domain events, inject event sink. Preserve native ConPTY, WSL, existing SSH behaviour and explicit tmux choice. Start/input/resize/interrupt/stop/exit semantics preserved; detach separate from stop at headless seam. Bound output/queues, define backpressure/cancellation. No privileged host execution endpoint.
Tests: fake CLI, binary/Unicode output, simultaneous read/write, slow consumer, exit and shutdown, repeated start/stop, detach vs stop, failure cleanup. Acceptance: no Tauri event calls in core, one process owner, desktop quit reaps children, headless proof survives client detach.
