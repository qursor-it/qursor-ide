# E2 — Native agents and profiles
Depends on E1. Read ADR-0060, 0061, 0062, 0004 and annex-A-cli-agent-patterns.md. Inspect agents/{mod,claude,codex}.rs, services/agent_cli.rs, profiles.rs, usage/, commands and tests under apps/desktop/src-tauri/src.
Extract descriptors and optional Spawn/Discovery/Transcripts/Status, binary discovery, profile resolution, native session-id mapping and usage collection separate from UI widget. Preserve argv, config-dir semantics, Windows PATH/PATHEXT, shell env, read-only store, resume. Existing profiles may reference local paths; never copy them blindly. Future capability metadata for install/native login/billing/usage, credentials opaque. No new CLI integrations or account rotation.
Tests: fixture transcripts, spawn args/env (no secrets), config dirs, unknown status, id adoption, invalid overrides, Windows paths, serialization redaction. Acceptance: Claude/Codex parity, fake spawn-only agent, no framework coupling or new network calls.
